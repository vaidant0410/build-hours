# Pocket World

A small, cartoonish open-world prototype for **Godot 4.3+**: four connected maps,
18 villagers you can chat with, and a chunky toon-shaded look with bold outlines.
"Pocket World" is a working title, so rename it whenever you like.

## Run it

1. Open `pocket-world/project.godot` in Godot 4.3 or newer.
2. Press **F5**. The game starts in Meadow Village.

| Action | Keyboard / mouse | Gamepad |
| --- | --- | --- |
| Move | WASD / arrow keys | Left stick |
| Sprint | Shift | LB |
| Jump | Space | A |
| Talk / read / next line | E or Enter | X |
| Look around | Click to capture the mouse, then move it (Esc releases) | Right stick |
| Turn camera | Z / C | |

## The maps

| Map | What's there | Villagers |
| --- | --- | --- |
| **Meadow Village** (hub) | Fountain plaza, 10 houses, market stalls, windmill hill, pumpkin farm, fishing pond. Portals north, east and west. | Mayor Bun, Pip the Baker, Old Tomo, Luma, Guard Gus |
| **Whispering Woods** | Dense forest, stream with a bridge, ranger cabin and campfire, giant mushroom grove, quiet pond, fireflies. | Ranger Hazel, Moss, Bramble, Wisp |
| **Sunny Shores** | Hills rolling down to a beach and open sea, dock and rowboat, beach huts, smoothie stand, lighthouse headland. | Captain Coral, Sunny, Keeper Wren, Shelly, Finn the Lifeguard |
| **Frosty Peaks** | Snowy hills ringed by mountains, igloo camp, frozen lake, snowman field, crystal lookout plateau, snowfall. | Yuki, Professor Frost, Pebble, Old Bjorn |

Walk through a glowing ring to travel. The HUD keeps count of how many villagers
you've met (`Friends met: x / 18`). Villagers mention each other across maps, which
gives you hooks for quests later.

## Project layout

```
autoload/game_state.gd        map travel + fade, friends met, input map
scenes/characters/            CharacterModel (primitive-built cartoon body), Player, NPC
scenes/world/                 Terrain, Portal, Sign, level root, Toon material helper
scenes/ui/hud.gd              area banner, friends counter, prompt, typewriter dialogue
assets/materials/             toon palette (StandardMaterial3D, toon diffuse + outline pass)
assets/props/                 ~65 prop scenes (trees, houses, windmill, lighthouse, igloo...)
levels/                       the four maps
shaders/water.gdshader        cartoon water
tools/                        world generator + dev tools (see below)
```

## Editing the world

The maps are ordinary `.tscn` files, so you can open them in the editor (or drive
them through the Godot MCP) and move things around by hand.

They were generated by `tools/build_world.py`. Layouts, villagers and dialogue live
in `tools/levels.py`, and the prop library is in `tools/props.py`. To make big changes
(more trees, a new map, new villagers), edit those files and run:

```
python3 tools/build_world.py              # rewrites materials, props and levels
python3 tools/build_world.py --preview    # also writes top-down PNG maps to tools/previews/
```

Re-running the generator **overwrites** the level files, so pick one workflow per
map: hand-edit it in the editor, or regenerate it from the script.

Useful knobs:

- **Villager looks:** each NPC exposes skin, shirt, pants, shoes, hair, hat
  (cap, top hat, beanie, straw, wizard, bow) and ears (bunny, cat, bear) in the
  Inspector, and the editor previews changes live.
- **Dialogue:** `lines` is said on the first meeting, `repeat_lines` afterwards.
- **Terrain:** the `Terrain` node regenerates in the editor when you change its
  hills, flattened areas (`flats`), carved rivers (`channels`), painted `paths`
  or colours. If you change the height formula in `terrain.gd`, mirror it in
  `TerrainFn` in `build_world.py`.
- **Portals:** set `target_map` (a key in `GameState.MAPS`) and `target_spawn`
  (a `Marker3D` name under the target level's `Spawns` node).
- **Adding a map:** add a builder function to `tools/levels.py`, register it
  in `LEVELS` and in `GameState.MAPS`, and connect a portal to it.

## Dev tools

```
# Gameplay smoke test: walking, talking, signs, portals, bridge, every map
godot --headless --path . res://tools/smoke_test.tscn

# Automated tour of every map, recorded to a video
godot --path . --fixed-fps 30 --write-movie /tmp/tour.avi res://tools/demo.tscn

# Screenshots: map id, output folder, then camera poses as "x,y,z,target_x,target_y,target_z"
godot --path . res://tools/screenshot.tscn -- meadow_village /tmp player "0,30,45,0,2,0"
```

## About the art

Everything is built from Godot primitive meshes with a shared toon palette, so
there are no imported model files. To swap in other models (for example Pocket
Town assets), replace the meshes inside `assets/props/<prop>.tscn` (or point a
prop at an imported `.glb`) and every map that uses that prop updates.
